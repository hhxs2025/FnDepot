# 📂 文件收集助手

一款专为飞牛 fnOS 开发的轻量级文件收集工具，帮你轻松收集团队成员的文件。

---

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 📋 创建收集任务 | 设置任务名称、文件大小限制、截止时间 |
| 📤 文件提交 | 提交者填写姓名，选择文件即可上传，支持多文件 |
| 📱 二维码分享 | 每个任务自动生成二维码，扫码即可提交 |
| 🔗 一键复制链接 | 复制收集链接，分享到微信、钉钉、邮件等 |
| 🔐 管理后台 | 查看所有任务、收集进度、已提交文件 |

---

## 🛠 技术栈

| 组件 | 技术 |
|------|------|
| 后端 | Flask + TinyDB |
| 前端 | 原生 HTML/CSS/JavaScript |
| 数据库 | TinyDB (JSON 文件) |
| 二维码 | qrcode 库 |

## 📦 安装方式

### 应用中心手动安装（推荐）

1. 下载 `file-collector-1.0.0.fpk`
2. 登录飞牛 fnOS → 应用中心 → 手动安装
3. 选择 `.fpk` 文件，按向导完成安装
4. 打开应用，使用默认账号登录
