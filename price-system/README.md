# 📊 物价系统 使用说明文档

> 版本：v1.0.0 | 适用于：飞牛 fnOS Native 应用


## 📖 简介

物价系统是一款专为飞牛 fnOS 开发的智能比价应用。记录商品在各店铺的价格，一键比价找到最划算的购买渠道，帮你省钱又省心。

**核心特点：轻量、免维护、数据本地存储。**


## ✨ 功能列表

| 功能 | 说明 |
|------|------|
| 📦 商品管理 | 添加、编辑、删除商品，支持分类和单位设置 |
| 💰 价格记录 | 记录商品在不同店铺的价格，支持地点、备注等详细信息 |
| 🏪 同物异店比价 | 同一商品在不同店铺的价格对比，推荐最优购买渠道 |
| 🔄 替代品比价 | 同分类中找出价格更低的替代品，帮你省钱 |
| 🔍 高级查询 | 按商品、店铺、时间范围筛选价格记录 |
| 📊 数据统计 | 商品数量、价格记录数、本周新增、涉及店铺数 |

## 📖 使用流程

管理员/用户操作：
1. 登录系统（默认 admin/admin123）
2. 添加商品（名称、分类、单位）
3. 记录价格（选择商品、填写价格和店铺）
4. 智能比价
   - 同物异店比价：选择商品，对比所有店铺价格
   - 替代品比价：输入商品名，找出更便宜的替代品
5. 高级查询：按商品、店铺、天数筛选价格记录


## 👤 用户操作指南

### 1. 登录系统

打开应用首页，输入用户名和密码登录。

### 2. 添加商品

点击「商品管理」标签：
- 输入商品名称（必填）
- 输入分类（如：蔬菜、饮料、日用品）
- 输入单位（如：个、斤、瓶）
- 点击「添加」按钮

### 3. 记录价格

点击「价格记录」标签：
- 选择商品
- 输入价格
- 输入店铺名称（必填）
- 可选：地点、备注
- 点击「记录」按钮

### 4. 智能比价

点击「智能比价」标签，有两种模式：

#### 模式一：同物异店比价
- 选择一个商品
- 点击「比价」按钮
- 系统展示该商品在所有店铺的价格排名
- 推荐最便宜的店铺

#### 模式二：替代品比价
- 输入商品名称
- 点击「找替代品」按钮
- 系统找出同分类中价格更低的替代品
- 显示可节省的金额

### 5. 高级查询

点击「查询」标签：
- 按商品筛选
- 按店铺名称筛选
- 按天数筛选（默认30天）
- 点击「查询」按钮


## 📊 比价模式详解

### 🏪 同物异店比价

| 项目 | 说明 |
|------|------|
| 用途 | 同一商品在不同店铺的价格对比 |
| 操作 | 选择一个商品 → 点击比价 |
| 输出 | 价格排名、均价、差价、推荐店铺 |
| 示例 | 可口可乐：A店3.5元、B店3.8元、C店3.2元 → 推荐C店 |

### 🔄 替代品比价

| 项目 | 说明 |
|------|------|
| 用途 | 同类商品中找出价格更低的替代品 |
| 操作 | 输入商品名称 → 点击找替代品 |
| 输出 | 替代品列表、价格对比、可节省金额 |
| 示例 | 原商品5元，替代品3.5元 → 可节省1.5元 |

## 🐛 常见问题

### Q1：登录失败怎么办？

确认用户名和密码是否正确。
默认账号：admin / admin123
如忘记密码，SSH 登录后重置。

### Q2：如何重置管理员密码？

SSH 登录飞牛，执行：

cd /vol1/@appcenter/price-system/server

python3 -c "
import hashlib
import os
os.chdir('/vol1/@appcenter/price-system/server')
from app import app, db, User
with app.app_context():
    user = User.query.filter_by(username='admin').first()
    if user:
        user.set_password('新密码')
        db.session.commit()
        print('密码重置成功')
    else:
        print('admin用户不存在')
"
### Q3：如何查看应用日志？

SSH 登录飞牛，执行：
cat /vol1/@appcenter/price-system/var/info.log

### Q4：数据如何备份？

备份 /vol1/@appcenter/price-system/var/ 目录下的所有文件即可。

### Q5：无法访问应用页面？

1. 检查应用是否处于「运行中」状态
2. 检查端口是否被占用：netstat -tlnp | grep 5668
3. 查看应用日志排查错误
